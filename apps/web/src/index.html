Install it in Figma

  1. Clone the repo and run npm install then npm run build.
  2. In the Figma desktop app: Plugins → Development → Import plugin from manifest…
  3. Pick apps/plugin/manifest.json, then run CopyPilot from Plugins → Development.

Everything runs locally. The plugin makes no network requests, and the rules come from the Material UX writing guide.
